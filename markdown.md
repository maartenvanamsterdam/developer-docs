# Markdown Cheatsheet

A quick reference for writing Markdown files.

---

# Headers

```md
# Large Title

## Subtitle

### Small Title

#### Smaller Title
```

Example:

# Large Title

## Subtitle

### Small Title

#### Smaller Title

---

# Bold & Italic Text

```md
**bold text**

_italic text_

**_bold italic_**
```

Example:

**bold text**

_italic text_

**_bold italic_**

---

# Inline Code

```md
`pnpm dev`
```

Example:

`pnpm dev`

---

# Code Blocks

````md
```bash
pnpm install
pnpm dev
```
````

Example:

```bash
pnpm install
pnpm dev
```

You can also use:

````
```ts
const name = "MVA Labs";
```
````

```ts
const name = "MVA Labs";
```

# Bullet Lists

```md
- First item

- Third item
```

Example:

- First item
- Second item
- Third item

---

# Numbered Lists

```md
1. First
2. Second
3. Third
```

Example:

1. First
2. Second
3. Third

# Links

Example:

```text
Ctrl + Shift + V
```

Or:

```text
Right click → Open Preview
```
