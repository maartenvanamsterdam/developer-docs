# Git Commit Conventions

## Format

```text
type: short description
```

## Examples

```text
feat: add GitHub Actions CI pipeline
chore: configure Vercel deployment checks
fix: resolve pnpm install issues in CI
refactor: reorganize frontend project structure
```

## Common Commit Types

| Type       | Description                                 |
| ---------- | ------------------------------------------- |
| `feat`     | New feature                                 |
| `fix`      | Bug fix                                     |
| `refactor` | Improve code without changing functionality |
| `chore`    | Tooling, configuration, CI/CD, maintenance  |
| `docs`     | Documentation                               |
| `style`    | Formatting or styling changes               |
| `test`     | Add or update tests                         |

## Guidelines

- Keep commits short and focused
- Use lowercase commit types
- Write commit messages in English
- Prefer one logical change per commit
- Use clear and descriptive wording
